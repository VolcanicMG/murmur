How it works

Four steps. One machine.

The whole path from microphone to text runs locally. There is no server to send your voice to.

1 · MicrophoneHold the key

The mic starts when the key goes down and stops when you let go. It is never left on.

2 · SpeechParakeet hears it

NVIDIA's Parakeet model turns audio into words on your CPU. Ten seconds takes about 0.3 s.

3 · CleanupA local model tidies

Fillers go, self-corrections apply, and your names are spelled your way.

4 · PasteText lands

The result is pasted at your cursor, and your clipboard is put back afterwards.

NetworkNot in the path. A cloud model is something you switch on yourself, and murmur warns you at startup when one is active.

Privacy

Your voice stays in the room.

Dictation hears everything you say to your computer. That is exactly why it should not run on someone else's.

Speech recognitionLocalParakeet runs on your CPU.
Text cleanupLocalA bundled model. Cloud only if you turn it on.
AudioNot keptUsed for the transcript, then discarded.
Password fieldsSkippedNothing said there is read, cleaned, shown or saved.
HistoryEncryptedUnder your Windows login. Private mode turns it off.
ClipboardRestoredAnd dictated text stays out of clipboard history.
Any appYour callRight-click a game or app to switch murmur off there.
Hotkeys

Four keys to learn.

Only the right-hand keys trigger, so your normal shortcuts keep working. Every key can be changed in Settings.

Right Ctrl holdDictate. Release to paste.
Right Ctrl tapHands-free. Stops when you do.
Right Alt holdCommand mode. Edit the selection.
Ctrl Alt MFix the last dictation and teach the dictionary.
Install

Three steps, no installer.

Step 1Download the zip

Get murmur-windows.zip from the latest release on GitHub.

Step 2Unzip it anywhere

About 780 MB once unpacked. The speech model is already inside.

Step 3Run murmur.exe

A one-minute setup picks your microphone, cleanup model and keys.

Heads up

Windows will warn you the first time. murmur is not code-signed yet, so Windows shows “Windows protected your PC”. Choose More info, then Run anyway. Every release lists a SHA-256 checksum so you can check the download is the one we built. The cleanup model is a separate download of about 6 GB that you start yourself.
